# SOMA · знак «рябь»

Визуальный знак приложения SOMA — три затухающие волны.

## Файлы в этой папке

- **`logo-header.svg`** — для шапки приложения (40×22, использует `currentColor` чтобы адаптироваться к теме)
- **`favicon.svg`** — для favicon (22×22, фиксированный цвет `#1a1a1a` для светлой темы)
- **`logo-large.svg`** — для splash-экранов и презентаций (320×180)
- **`app-icon-512.svg`** — квадратный иконка для PWA / iOS (512×512 с фоном `#fafaf9`)
- **`preview.html`** — визуальное превью всех применений, открой в браузере чтобы увидеть как должно выглядеть

## Концепция

- Три волны одна под другой, затухающие по прозрачности (1.0, 0.55, 0.25)
- Каждая волна — `Q` Bezier-кривая, дважды повторённая (T-команда)
- `stroke-linecap: round` для мягких концов
- В шапке цвет через `currentColor` — автоматически следует за `--ink` темы

## Параметры волны (для шапки 40×22)

```
viewBox: 0 0 40 22
stroke-width: 0.9
linecap: round

Y координаты волн: 8, 14, 20
Длина волны: пик в (12, 4), седло в (18, 8), пик в (24, 4), и так далее
```

## Использование в шапке приложения

Знак ставится **слева от** существующего блока с SOMA / a visual study.
Между знаком и текстом — отступ ~12px.

Ссылка на структуру шапки см. в `preview.html`.
